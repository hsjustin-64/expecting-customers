# VS Code에서 실행하기

이 폴더에는 화면 소스, Python API 서버, Prophet 예측 엔진, 상권 모델, 공개 체험 서버, 테스트, 설치 파일과 VS Code 설정이 들어 있습니다. 기존 디자인과 기능에 Live Server 연결과 내 매장 초기 설정을 추가했습니다.

## 처음 한 번

1. ZIP을 압축 해제합니다. VS Code에서 **파일 → 폴더 열기**로 `morning-cup-vscode` 폴더를 엽니다. ZIP 안에서 직접 실행하지 마세요.
2. Windows x64에서 Python 3.10~3.12의 64비트 버전을 설치합니다. 설치할 때 PATH 추가를 선택합니다.
3. VS Code 확장 **Python**, **Python Debugger**, **Live Server**를 설치합니다. 추천 확장 목록에도 들어 있습니다.
4. `install.bat`를 실행하고 설치 완료를 기다립니다. 최초 설치에는 인터넷 연결이 필요합니다. 설치 마지막에 실제 Prophet을 학습하고 다음 날을 예측하여 작동 여부를 자동 검사합니다. 실패 메시지가 나오면 설치가 완료된 것이 아닙니다.

## Live Server로 열기

1. **F5**를 눌러 Python 서버를 실행합니다. 또는 `start-backend.bat`를 더블 클릭합니다. 둘 중 하나만 실행하세요.
2. 폴더 최상단의 **index.html**을 우클릭 → **Open with Live Server**를 선택합니다.
3. `http://127.0.0.1:5500/static/index.html`에서 같은 모닝컵 화면이 열립니다.
4. Python 서버 창을 열어 둔 채 사용하세요. CSS·JS·HTML을 수정하면 Live Server가 화면을 새로고침합니다. Python 파일 수정 후에는 서버를 다시 시작해야 합니다.

화면은 Live Server의 5500 포트, 예측·저장은 Python의 8765 포트를 사용합니다. Live Server만 실행하면 서버에 연결할 수 없다는 안내가 나옵니다. Python·Prophet이 수행하던 계산을 가짜 JavaScript 계산으로 바꾸지 않았습니다.

**8765 포트를 이미 사용 중이라는 메시지:** 예전에 실행한 모닝컵 서버를 먼저 종료한 뒤 이 폴더의 서버를 실행하세요. 이전 버전의 서버는 Live Server 연결을 지원하지 않을 수 있습니다.

## Live Server 없이 실행

설치 후 `start.bat` 실행 → `http://127.0.0.1:8765`에서 동일하게 사용할 수 있습니다.

## 포함된 소스

- `index.html`: Live Server 시작 페이지
- `static/index.html`, `style.css`, `app.js`, `area.js`, `setup.js`, `shop-editor.js`: 전체 화면·스타일·화면 동작·상권 설정
- `app.py`: API·저장·CSV·샘플 데이터 생성
- `engine.py`: 실제 Prophet 학습·예측·발주·검증
- `areas.py`: 상권별 변수·일정 검증
- `demo_server.py`: 접속자별로 분리되는 공개 샘플 체험 서버
- `.vscode/`: 실행·디버깅·Live Server 설정
- `requirements*.txt`: 설치 의존성 및 기존 버전 목록
- `tests.py`, `test_areas.py`, `test_demo.py`, `test_live_server.py`: 테스트
- `install.py`, `check_environment.py`: 컴퓨터별 환경 설치와 실제 Prophet 실행 검사
- 기존 `README.md`, `VERIFICATION.md`, 실행·설치 BAT 파일
- `SOURCE_MANIFEST.json`: 원본 소스 포함 여부와 파일 해시

가상환경 `.venv`, 자동 생성 캐시·로그·사용자 DB는 소스 코드가 아니므로 압축에 넣지 않았습니다. 각 컴퓨터에서 설치 파일로 의존성을 새로 설치합니다. Windows 긴 경로 제한을 피하기 위해 Python 환경은 `%LOCALAPPDATA%/MCup/프로젝트별ID`에 생성하고, VS Code 설정과 `.python-path`를 자동 갱신합니다. 폴더를 옮기거나 다른 PC로 복사하면 `install.bat`를 다시 실행하세요. 첫 화면에서 **내 매장으로 시작**하면 매장 이름과 상권을 선택하고 빈 매장으로 시작합니다. **샘플로 체험**을 선택할 때만 가상 판매 이력 900행을 생성합니다. 매장 설정에서 메뉴·가격·재료·레시피를 입력한 뒤 판매 CSV 양식을 내려받아 실제 판매 이력을 업로드하세요. 데이터는 이 폴더의 data 하위 SQLite 파일에만 저장됩니다. 다른 사람에게는 이 ZIP을 전달하세요. 사용 중인 data 폴더를 함께 전달하면 매장 데이터도 복사됩니다.

## 검증

```powershell
& (Get-Content .python-path) -m unittest tests test_areas.AreaTests test_demo test_live_server test_setup
```

공개 체험 링크는 별도로 실행되는 임시 터널입니다. 이 ZIP 자체가 기존 공개 링크를 자동으로 유지하거나 새 링크를 생성하지는 않습니다. 로컬 실행에는 Cloudflare나 외부 계정이 필요 없습니다.
