# 한글 Windows 사용자 경로 오류 수정

증상: An error occurred when parsing Stan csv

한글 임시 경로에서 동일 오류를 재현했습니다. 내부 원인은 Stan CSV 주석의 Windows ANSI 인코딩을 CmdStanPy가 UTF-8로 해석하면서 발생한 UnicodeDecodeError였습니다. 수정 후 동일 경로에서 실제 Prophet 학습·예측에 성공했고 테스트 27개가 통과했습니다. 팀원 PC의 최종 재확인은 필요합니다.

## 이미 설치하여 사용하는 팀원

1. 실행 중인 Python 서버를 종료하세요. F5로 실행했다면 VS Code에서 Shift+F5를 누르세요.
2. 패치 ZIP의 engine.py, stan_compat.py, check_environment.py를 기존 app.py와 같은 폴더에 복사하세요. engine.py와 check_environment.py는 덮어씁니다. 직접 수정한 코드가 있다면 먼저 백업하세요.
3. start-backend.bat 또는 F5로 서버를 다시 실행하세요.
4. 홈페이지를 새로고침한 뒤 예측 버튼을 누르세요.

패치에는 data 폴더나 매장 데이터가 없습니다. 이 문제만으로 매장 설정을 초기화하거나 Python을 재설치할 필요는 없습니다. 전체 소스를 새 폴더에서 시작하는 경우에는 시작하기.md에 따라 install.bat부터 실행하세요.

## 변경 범위

Windows에서만 CSV 주석을 UTF-8로 먼저 검사하고, 실패한 주석만 Windows의 활성 ANSI 코드 페이지로 엄격하게 읽습니다. 숫자 예측값, 학습 데이터, 모델 수식은 바꾸지 않습니다. 잘못된 바이트를 임의 문자로 대체하지 않습니다.
