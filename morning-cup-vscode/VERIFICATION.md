# 실행 확인 (2026-09-13)

- Python 3.10 / Windows 환경에서 Prophet 1.4.0, Flask 3.1.3 실행.
- 자동 테스트 9개 통과: 품질 필터·예약 분리, CSV 중복/음수/미래일 거부, 만료 재고 제외, 납기와 마감, 묶음 올림, 오늘 사용량 차감, 휴무, 예보 시각 검증, 실제 매장 전환과 업로드 실패 시 보존, Prophet 예측→발주 CSV, 마감 갱신, 외부 Origin 요청 거부. 일부 테스트는 여러 조건을 함께 검증함.
- pip check: 의존성 충돌 없음.
- JavaScript 구문 검사 및 Python 컴파일 통과.
- 브라우저에서 샘플 900행 로드 → 계산 버튼 → 5개 메뉴 Prophet 결과 → 발주 초안 저장과 CSV 링크 표시 확인.
- 5개 메뉴 × 최근 7개 평가일 = 총 35회 순차 예측 실행 완료.
- 샘플 데이터의 달력 기반 MAE: 햄치즈 3.83 / 기준 3.07, 에그 4.01 / 기준 3.71, 크림치즈 2.38 / 기준 3.11, 연어 3.08 / 기준 3.50, 라떼 1.63 / 기준 1.93. 샘플 결과이며 실제 성능 주장이 아님.

실제 매장 POS·날씨 API·거래처 연동, 인터넷 공개 배포, 모바일 실기기 검증은 수행하지 않았음.

## 상권 설정 추가 검증

- `python -m unittest test_areas.AreaTests test_areas.AreaApiTests`: 기존 회귀 테스트 포함 총 17개 통과.
- 일정 시작·종료 포함, 확인 기간 외 미확인 처리, 불완전 확인 기간의 학습 차단, 일정 중복의 합집합 처리, 동일 변수 패턴 제외, 희소 이력 제외, 다른 상권의 잘못된 일정 거부 확인.
- 합성 데이터에서 반복되는 기간 효과를 실제 Prophet이 학습하고 미래 해당 여부에 따라 예측이 달라지는지 확인. 이는 기능 검증이며 실제 매장 정확도 검증이 아님.
- 상권 저장 시 기존 판매 데이터 보존, 이전 예측·발주 무효화, 잘못된 저장 요청의 원자적 거부 확인.
