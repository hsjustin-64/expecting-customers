# 다른 PC 실행을 위한 변경 및 검증

검증 날짜: 2026-09-14

- 홈페이지 HTML/CSS/JavaScript, Flask API, 실제 Prophet 엔진, 상권 변수, 독립 매장 초기 설정, 메뉴·재료·레시피 편집을 포함합니다.
- `install.bat`는 Windows x64의 Python 3.12 / 3.11 / 3.10을 찾습니다. 없으면 PATH의 Python을 확인합니다.
- `install.py`는 Windows 긴 경로 제한을 피하도록 사용자 LocalAppData/MCup 아래에 프로젝트별 Python 환경을 생성합니다. 설치 후 실제 Prophet 학습·예측 검사에 성공해야 VS Code 인터프리터와 실행 파일용 경로를 저장합니다.
- Live Server 화면은 5500, Python API는 8765에서 실행합니다. 홈페이지의 계산과 저장은 Python 서버가 담당합니다.

## 실제 수행한 검증

1. ZIP을 공백이 있는 별도 폴더에 압축 해제했습니다.
2. Windows x64 / Python 3.10 새 가상환경에 로컬 보관 wheel로 requirements-demo.txt의 의존성을 새로 설치했습니다.
3. check_environment.py에서 Prophet 1.4.0이 한국 공휴일·주간 계절성·기온 회귀변수를 포함해 90일 이력을 학습하고 다음 날의 유한한 예측값과 구간을 반환했습니다.
4. 추출한 소스에서 테스트 23개가 통과했습니다. 예측·발주·상권·샘플 격리·Live Server CORS·정적 파일·새 매장 초기화와 저장을 포함합니다.
5. 수정한 JavaScript 3개 파일의 구문 검사를 통과했습니다.
6. 패키징 시 원본 소스 18개 파일의 누락이 없음을 검사하고 ZIP 무결성과 파일별 해시를 확인했습니다.

## 검증 범위

물리적으로 다른 PC나 Python 3.11/3.12에서는 아직 실행하지 않았습니다. 새 PC에서의 PyPI 네트워크 설치는 인터넷·프록시 설정에 영향을 받을 수 있습니다. 따라서 설치 시마다 실제 Prophet 실행 검사를 수행합니다. 최초 설치에는 인터넷 연결이 필요합니다. 설치용 바이너리, 개인 매장 DB, 생성된 Python 환경은 ZIP에 넣지 않으며 전체 프로그램 소스는 포함합니다.

기존 VERIFICATION.md는 초기 버전 검증 기록입니다. 현재 실행 방법은 시작하기.md를 기준으로 사용하세요.
